The goal of LQR

\(\downarrow\)

• Stabilize the system around state \(x_t = 0\) with control \(u_t = 0\)

LQR: assumptions

• You know the dynamics model of the system
• It is linear: \(\mathbf{x}_{t+1} = Ax_t + Bu_t\)

• There is an instantaneous cost associated with being at state \(x_t\) and taking the action : \(\mathbf{u}_t: c(\mathbf{x}_t, \mathbf{u}_t) = \mathbf{x}_t^T Q \mathbf{x}_t + \mathbf{u}_t^T R \mathbf{u}_t\)

\(\color{red}\uparrow\)
Quadratic state cost: Penalizes deviation from the zero vector

\(\color{red}\nwarrow\)
Quadratic control cost: Penalizes high control signals

\(\color{red}\uparrow\)

\(\color{red}\nearrow\)

Square matrices Q and R must be positive definite:
\(Q = Q^T\) and \(\forall x, x^T Q x > 0\)
\(R = R^T\) and \(\forall u, u^T R u > 0\)
i.e. positive cost for ANY nonzero state and control vector

Finite-Horizon LQR

• Idea: finding controls is an optimization problem
• Compute the control variables that minimize the cumulative cost

\[ \begin{align} u_0^*, \ldots, u_{N-1}^* &= \text{argmin}_{u_0, \ldots, u_N} \sum_{t=0}^{N} c(\mathbf{x}_t, \mathbf{u}_t) \\ &\text{s.t.} \\ \mathbf{x}_1 &= A\mathbf{x}_0 + B\mathbf{u}_0 \\ \mathbf{x}_2 &= A\mathbf{x}_1 + B\mathbf{u}_1 \\ &\vdots \\ \mathbf{x}_N &= A\mathbf{x}_{N-1} + B\mathbf{u}_{N-1} \end{align} \]

We could solve this as a constrained nonlinear optimization problem. But, there is a better way: we can find a closed-form solution.

What happens in the general nonlinear case?

\[ u_0^*, \ldots, u_{N-1}^* = \arg\min_{u_0, \ldots, u_N} \sum_{t=0}^{N} c(x_t, u_t) \] \[ \begin{aligned} \mathbf{x}_1 &= f(\mathbf{x}_0, \mathbf{u}_0) \\ \mathbf{x}_2 &= f(\mathbf{x}_1, \mathbf{u}_1) \\ &\vdots \\ \mathbf{x}_N &= f(\mathbf{x}_{N-1}, \mathbf{u}_{N-1}) \end{aligned} \]

Arbitrary differentiable functions \(c()\), \(f()\)

Idea: iteratively approximate solution by solving linearized versions of the problem via LQR

Iterative LQR (iLQR)

Given an initial sequence of states \(\bar{x}_0, \ldots, \bar{x}_N\) and actions \(\bar{u}_0, \ldots, \bar{u}_N\):

Linearize dynamics around that initial sequence:

\[ f(x_t, u_t) \approx \underbrace{f(\bar{x}_t, \bar{u}_t)}_{\mathbf{b}_t} + \underbrace{\frac{\partial f}{\partial x} (\bar{x}_t, \bar{u}_t)}_{A_t}\underbrace{(x_t - \bar{x}_t)}_{\delta \mathbf{x}_t} + \underbrace{\frac{\partial f}{\partial u} (\bar{x}_t, \bar{u}_t)}_{B_t}\underbrace{(u_t - \bar{u}_t)}_{\delta \mathbf{u}_t} = \tilde{f}(\delta \mathbf{x}_t, \delta \mathbf{u}_t) \]

Do a Taylor expansion of the cost:

\[ c(x_t, u_t) \approx c(\bar{x}_t, \bar{u}_t) + \underbrace{\nabla_{x,u} c(\bar{x}_t, \bar{u}_t)}_{\mathbf{h}_t} \begin{bmatrix} \delta \mathbf{x}_t \\ \delta \mathbf{u}_t \end{bmatrix} + \frac{1}{2} \begin{bmatrix} \delta \mathbf{x}_t \\ \delta \mathbf{u}_t \end{bmatrix}^T \underbrace{\nabla^2_{x,u} c(\bar{x}_t, \bar{u}_t)}_{H_t} \begin{bmatrix} \delta \mathbf{x}_t \\ \delta \mathbf{u}_t \end{bmatrix} = \tilde{c}(\delta \mathbf{x}_t, \delta \mathbf{u}_t) \]

Apply LQR backward pass on the approximate dynamics \(\tilde{f}(\delta \mathbf{x}_t, \delta \mathbf{u}_t)\) and cost \(\tilde{c}(\delta \mathbf{x}_t, \delta \mathbf{u}_t)\) to compute controller and cost-to-go parameters.

Do an LQR forward pass to get \(\delta \mathbf{u}_t\) and \(\delta \mathbf{x}_t\) and update state and action sequence and \(\bar{x}_0, \ldots, \bar{x}_N\) and \(\bar{u}_0, \ldots, \bar{u}_N\)

Iterative LQR: convergence & tricks

  • New state and action sequence in iLQR is not guaranteed to be close to the linearization point (so linear approximation might be bad)

  • Trick: try to penalize magnitude of \(\delta u_t\) and \(\delta x_t\)
    Replace old LQR linearized cost with \((1 - \alpha) \, \tilde{c}(\delta \mathbf{x}_t, \delta \mathbf{u}_t) + \alpha \left( \| \delta \mathbf{x}_t \|^2 + \| \delta \mathbf{u}_t \|^2 \right)\)

  • Problem: Can get stuck in local optima, need to initialize well

  • Problem: Hessian might not be positive definite

Model Predictive Control

while True:

  • observe the current state \(x_0\)

  • run LQR/iLQR or LQG/iLQG or other planner to get \({u}_0, \ldots, {u}_{N-1}\)

  • Execute \(u_0\)

Possible speedups:

  1. Don’t plan too far ahead with LQR
  2. Execute more than one planned action
  3. Warm starts and initialization
  4. Use faster / custom optimizer (e.g. CPLEX, sequential quadratic programming)

do supervised learning to minimize \(\sum_{t} \left\| f_{\theta}(x_t, u_t) - x_{t+1} \right\|^2\)

and then use the learned model for planning

Possibly a better idea: instead of minimizing single-step prediction errors, minimize multi-step errors.

See “Improving Multi-step Prediction of Learned Time Series Models” by Venkatraman, Hebert, Bagnell

Possibly a better idea: instead of predicting next state predict next change in state.

See “PILCO: A Model-Based and Data-Efficient Approach to Policy Search” by Deisenroth, Rasmussen

Model-based RL

Collect initial dataset \(D = \{(x_t, u_t, x_{t+1})\}\)

  • Fit dynamics model \(f_{\theta}(x_t, u_t)\)

  • Plan through \(f_{\theta}(x_t, u_t)\) to get actions

  • Execute first action, observe new state \(x_{t+1}\)

  • Append \((x_t, u_t, x_{t+1})\) to \(D\)

How do we plan through a learned model?

  • iLQR needs \(\frac{\partial f}{\partial x}, \frac{\partial f}{\partial u}\) and \(\nabla^2 c\): the model and the cost must be smooth, and the Hessian should be positive definite

Often that is not the case:

  • \(f_\theta\) is a neural network (gradients exist but are noisy, and the linearization can be very poor far from the data)

  • \(f\) is a black-box simulator with contacts (no gradients at all)

  • \(c\) is discontinuous, e.g. an indicator for collisions or reaching a goal region

Idea: don’t differentiate at all. Sample many action sequences, roll them out through the model in parallel, and average the good ones

Model Predictive Path Integral Control (MPPI)

Given the current state \(x_0\) and a nominal action sequence \(\bar{u}_0, \ldots, \bar{u}_{N-1}\) (e.g. last plan, shifted by one step):

  1. Sample \(K\) perturbed sequences: \(\epsilon^k_t \sim \mathcal{N}(0, \Sigma)\), \(\quad u^k_t = \bar{u}_t + \epsilon^k_t\)

  2. Roll out each one through the model: \(x^k_{t+1} = f(x^k_t, u^k_t)\), starting from \(x_0\)

  3. Compute the cost of each rollout: \(S_k = \sum_{t=0}^{N-1} c(x^k_t, u^k_t) + c_N(x^k_N)\)

  4. Weight rollouts with a softmin over costs (temperature \(\lambda\)): \[ w_k = \frac{\exp\left(-\frac{1}{\lambda}\left(S_k - \min_j S_j\right)\right)}{\sum_{j=1}^{K} \exp\left(-\frac{1}{\lambda}\left(S_j - \min_j S_j\right)\right)} \]

  5. Update the nominal sequence: \(\bar{u}_t \leftarrow \bar{u}_t + \sum_{k=1}^{K} w_k \, \epsilon^k_t\)

  6. Execute \(\bar{u}_0\), observe the new state, shift the sequence, repeat (MPC)

Steps 1–3 are \(K\) independent rollouts, so they map perfectly onto a GPU: thousands of rollouts at 40+ Hz on a real vehicle

MPPI in action: reaching a goal

Point mass with friction: \(m\ddot{p} = u - \alpha \dot{p}\)

Cost: \(c(x, u) = \|p - p_{\text{goal}}\|^2_{Q} + \|\dot{p}\|^2 + \|u\|^2_R\)

At every step:

• Blue: the \(K\) sampled rollouts, opacity \(\propto w_k\)

• Red: the new nominal plan \(\bar{u} + \sum_k w_k \epsilon^k\)

• Black: the executed path (only \(\bar{u}_0\) is applied, then replan)

Notice how the samples are spread out when far from the goal and collapse around it once we arrive: the weights and the warm start do the work, no gradients needed

MPPI: properties & tricks

  • \(\lambda \to 0\): only keep the best rollout (greedy). \(\lambda \to \infty\): plain average of all samples. In between: a smoothed, weighted average of the good samples

  • Derivative-free: works with any model you can evaluate, including neural networks and simulators with contact, and with discontinuous costs

  • Warm start is essential: reuse last plan shifted by one step. With a good warm start, one MPPI update per control step is often enough

  • Problems: \(K\) needs to grow with the action dimension and horizon; exploration noise \(\Sigma\) has to be tuned; no local convergence guarantee like iLQR

See “Model Predictive Path Integral Control: From Theory to Parallel Computation”

“Information Theoretic MPC for Model-Based Reinforcement Learning” by Williams, Aldrich, Theodorou et al. (2017),

where MPPI is used to drive the AutoRally car aggressively with a learned neural network dynamics model

A closely related idea: the Cross-Entropy Method (CEM)

• MPPI keeps a single nominal sequence \(\bar{u}\) and nudges it with a weighted average of the noise

• CEM instead maintains a distribution over action sequences, \(q(u_{0:N-1}) = \mathcal{N}(\mu, \Sigma)\), and iteratively refits it to the best samples

• Comes from rare-event simulation (Rubinstein, 1997): to estimate the probability of a rare event, iteratively move the sampling distribution towards the region where the event happens

For optimization the “rare event” is “cost below the current threshold”, and the distribution concentrates on low-cost action sequences

Cross-Entropy Method (CEM) for planning

Given the current state \(x_0\) and an initial distribution \(\mu_t, \Sigma_t\) over actions (e.g. \(\mu\) = last plan shifted by one step, \(\Sigma\) reset to a large value):

Repeat for a few iterations:

  1. Sample \(K\) action sequences: \(u^k_{0:N-1} \sim \mathcal{N}(\mu_{0:N-1}, \Sigma_{0:N-1})\)

  2. Roll out each one through the model: \(x^k_{t+1} = f(x^k_t, u^k_t)\), starting from \(x_0\)

  3. Compute the cost of each rollout: \(S_k = \sum_{t=0}^{N-1} c(x^k_t, u^k_t) + c_N(x^k_N)\)

  4. Keep the \(M \ll K\) lowest-cost sequences, the elites \(\mathcal{E}\)

  5. Refit the distribution to the elites: \[ \mu_t \leftarrow \frac{1}{M} \sum_{k \in \mathcal{E}} u^k_t \qquad \Sigma_t \leftarrow \frac{1}{M} \sum_{k \in \mathcal{E}} (u^k_t - \mu_t)(u^k_t - \mu_t)^T \]

Execute \(\mu_0\), observe the new state, shift \(\mu\), repeat (MPC)

Step 5 is a maximum-likelihood fit of a Gaussian to the elites, i.e. it minimizes the cross-entropy between the elite distribution and \(q\), hence the name

CEM vs. MPPI

CEM MPPI
What is updated mean \(\mu\) and covariance \(\Sigma\) nominal sequence \(\bar{u}\) only (\(\Sigma\) fixed)
How samples are used hard threshold: top \(M\) elites, equal weight soft weights \(w_k \propto \exp(-S_k / \lambda)\) on all samples
Iterations per step usually several (distribution needs to shrink) often one, thanks to warm start
Hyperparameters \(K\), \(M\), initial \(\Sigma\), # iterations \(K\), \(\lambda\), \(\Sigma\)
Behavior more exploitative, converges quickly, can collapse too early smoother updates, more robust to noisy costs

  • Both are derivative-free, embarrassingly parallel, and work with learned models and discontinuous costs

  • Both scale poorly with action dimension and horizon: a Gaussian over \(N \cdot \dim(u)\) variables gets very wide, very fast

  • Tricks: keep the top elites across iterations, smooth \(\mu\) over time (colored noise), sample in a low-dimensional space of action splines

CEM was the planner of choice in many model-based RL papers, e.g. “Deep RL in a Handful of Trials using Probabilistic Dynamics Models” (PETS, Chua et al. 2018) and “Learning Latent Dynamics for Planning from Pixels” (PlaNet, Hafner et al. 2019)

• What can we do when \(x_{t+1} = A_t x_t + B_t u_t\) and \(c(x_t, u_t) = x_t^T Q x_t + u_t^T R u_t\) ?

• Turns out, the proof and the algorithm are almost the same

\(P_0 = Q_N\)

// n is the # of steps left

for n = 1…N

\(K_n = -\left(R_{N-n} + B_{N-n}^T P_{n-1} B_{N-n}\right)^{-1} B_{N-n}^T P_{n-1} A_{N-n}\)

\(P_n = Q_{N-n} + K_n^T R_{N-n} K_n + (A_{N-n} + B_{N-n} K_n)^T P_{n-1} (A_{N-n} + B_{N-n} K_n)\)

Optimal controller for n-step horizon is \(u_n = K_n x_n\) with cost-to-go \(J_n(x) = x^T P_n x\)

Appendix #2 (optional reading) Why not use PID control?

• We could, but:

• The gains for PID are good for a small region of state-space.

• System reaches a state outside this set → becomes unstable

• PID has no formal guarantees on the size of the set

• We would need to tune PID gains for every control variable.

• If the state vector has multiple dimensions it becomes harder to tune every control variable in isolation. Need to consider interactions and correlations.

• We would need to tune PID gains for different regions of the state-space and guarantee smooth gain transitions

• This is called gain scheduling, and it takes a lot of effort and time

LQR addresses these problems

Appendix #4 (optional reading) LQR extensions: trajectory following

• You are given a reference trajectory (not just path, but states and times, or states and controls) that needs to be approximated

\(\mathbf{x}_0^*, \mathbf{x}_1^*, \ldots, \mathbf{x}_N^*\)

\(\mathbf{u}_0^*, \mathbf{u}_1^*, \ldots, \mathbf{u}_N^*\)

Linearize the nonlinear dynamics \(x_{t+1} = f(x_t, u_t)\) around the reference point \((x^*_t, u^*_t)\):

\(x_{t+1} \simeq f(x^*_t, u^*_t) + \frac{\partial f}{\partial x}(x^*_t, u^*_t)(x_t - x^*_t) + \frac{\partial f}{\partial u}(x^*_t, u^*_t)(u_t - u^*_t)\)

\(\bar{x}_{t+1} \simeq A_t \bar{x}_t + B_t \bar{u}_t\)

\(c(x_t, u_t) = \bar{x}_t^T Q \bar{x}_t + \bar{u}_t^T R \bar{u}_t\)

where

\(\bar{x}_t = x_t - x_t^*\)

\(\bar{u}_t = u_t - u_t^*\)

Trajectory following can be implemented as a time-varying LQR approximation. Not always clear if this is the best way though.

Appendix #5 (optional reading) LQR with nonlinear dynamics, quadratic cost

LQR variants: nonlinear dynamics, quadratic cost

What can we do when \(x_{t+1} = f(x_t, u_t)\) but the cost is quadratic \(c(x_t, u_t) = \bar{x}_t^T Q \bar{x}_t + \bar{u}_t^T R \bar{u}_t\) ?

We want to stabilize the system around state \(x_t = 0\)

But with nonlinear dynamics we do not know if \(u_t = 0\) will keep the system at the zero state.

\(\rightarrow\) Need to compute \(u^*\) such that \(0_{t+1} = f(0_t, u^*)\)

Taylor expansion: linearize the nonlinear dynamics around the point \((0, u^*)\)

\[ \mathbf{x}_{t+1} \simeq f(\mathbf{0}, \mathbf{u}^*) + \underbrace{\frac{\partial f}{\partial \mathbf{x}}(\mathbf{0}, \mathbf{u}^*)(\mathbf{x}_t - \mathbf{0})}_{\mathbf{A}} + \underbrace{\frac{\partial f}{\partial \mathbf{u}}(\mathbf{0}, \mathbf{u}^*)(\mathbf{u}_t - \mathbf{u}^*)}_{\mathbf{B}} \]

\(\mathbf{x}_{t+1} \simeq A \mathbf{x}_t + B(\mathbf{u}_t - \mathbf{u}^*)\)

Solve this via LQR
